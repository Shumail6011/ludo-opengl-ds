# ludo-opengl-ds
🎲 First OpenGL-based Ludo Game in our university's history! Built from scratch using C++17, OpenGL 3.3, and core Data Structures (Graph, Circular Linked List, Queue, Stack, 2D Matrix). Features real-time rendering, token animations, kill system, sound effects &amp; undo. — Data Structures Course, 4th Semester
